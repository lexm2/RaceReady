# Rule 6: World Sailing Regulations

**Part 1 — Fundamental Rules**

**Source:** Racing Rules of Sailing 2021-2024, World Sailing  
https://www.sailing.org/inside-world-sailing/rules-regulations/racingrules/

---

## 6.1

Competitors, boat owners, and support persons must comply with designated World Sailing Regulations, including the:
- Advertising Code
- Anti-Doping Code
- Code of Ethics
- Eligibility Code
- Sailor Categorization Code

## 6.2

"The rules of Part 5 do not apply unless protests are permitted in the Regulation alleged to have been broken."
