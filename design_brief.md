## Typography

### Montserrat — Display / Headings
**Source:** Google Fonts (free)

| Use | Size |
|-----|------|
| H1 — Page Title | 48px, Bold |
| H2 — Section Header | 32px, SemiBold |
| H3 — Card Title | 24px, SemiBold |

**Rationale:** Geometric sans-serif with a sporty, confident feel. Works well on dark backgrounds.

---

### IBM Plex Sans — Body / UI
**Source:** Google Fonts (free)

| Use | Size |
|-----|------|
| Body Copy | 16px, Regular |
| Labels / Captions | 14px, Regular |
| Button Text | 14px, Medium |

**Rationale:** Designed for screen readability. Pairs cleanly with Montserrat for body and UI text.
