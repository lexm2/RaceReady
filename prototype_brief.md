## One Question This Prototype Answers

Do users understand the overall structure and navigation of the app well enough to find the tools they need?

---

## Two Key Features

### 1. Starboard Showdown (Game)
Addresses user need #5 from A1: sailors need to practice with realistic scenarios because studying words alone doesn't build the recognition needed in real situations. The game lets users under real time pressure practice making rules decisions.

### 2. Scenario Quiz Mode
Addresses user need #2 from A1: sailors need to understand the nuances of rules because simple rules have subtle details that are easy to miss until you're in a race. The quiz presents scenario based questions that highlight these subtle distinctions, forcing users to think carefully rather than rely on surface-level memorization like Quizlet.
